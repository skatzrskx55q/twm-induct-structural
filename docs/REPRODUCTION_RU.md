# Руководство по воспроизведению

1. Установите зависимости по [README_RU](../README_RU.md). В среде подготовки проверялся только CPU.
2. `python verify_integrity.py` проверяет SHA-256 всех распространяемых исходных файлов без ML-зависимостей.
3. `python run.py check` выполняет `python -m pytest -q -p no:cacheprovider tests/test_structural.py` в `research/TWM_INDUCT_STRUCTURAL_INDUCTION_2026-11-04`. Код ошибки сохраняется, в том числе при провале теста.
4. `python run.py --keep ../experiment demo` выполняет `python code/structural_rollout.py --seeds 17,29,43 --modes conditioned,static,ablate,E36,random`. Копия данных и новые результаты остаются в `../experiment`. Перед длительным запуском прочитайте исходный README.
5. Обучение или расширенный эксперимент: `python code/structural_experiment.py --steps 850 --seeds 17,29,43 --modes conditioned,static`. Работайте в отдельной копии, сохраняйте оригиналы и учитывайте условия исторического протокола и разблокировки EXAM. Не подбирайте параметры по опубликованным ответам EXAM. Для Bash может потребоваться Linux/WSL.

## Метрики
Открытый L2/L3 H16: conditioned 76/240 и 102/240 против static 65/240 и 82/240, против E36 84/240 и 108/240. Интерпретируйте H90/H16 и точность конечного состояния/всей траектории по исходному протоколу, а не как единый benchmark. NLL: меньше — лучше. Исходные отчёты содержат знаменатели и отрицательные контроли.
